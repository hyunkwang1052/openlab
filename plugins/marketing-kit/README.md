# marketing-kit

소상공인 사장님의 **"우리 가게 홍보물"**을 대화 한 번으로 끝까지 만들어 주는 Claude Code 플러그인입니다.

따뜻한 인터뷰로 가게 이야기를 듣고, 가게 이름·슬로건·로고와 색·글씨체(디자인 시트)를 정한 뒤, 같은 디자인으로 홍보물 4가지를 만듭니다. 원하면 인터넷에 올려 링크 하나로 공유할 수 있게 해 줍니다.

## 만드는 것

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| 1. 인터뷰 | 한 번에 한 질문씩 가게 이야기 듣기 | `01_brand.md` (가게 재료·슬로건 후보) |
| 2. 디자인 시트 | 이름·슬로건 고르기, 참고 사이트 고르기 → 색·폰트·워드마크 로고 | `brand-skill/` (재사용 가능한 '내 브랜드 스킬') |
| 3. 홍보물 4종 | 브랜드 스킬 그대로 입혀서 제작 | 홈페이지 · 소개 슬라이드 6장 · 인스타 카드뉴스 5장 · 명함+메일 서명 |
| 4. 올리기 (선택) | 모음 페이지 · 휴대폰 화면 · 카톡 미리보기(오픈그래프) · Vercel 배포 | `https://<가게>.vercel.app` |

- 단계마다 멈춰서 보여 주고 확인을 받습니다.
- 단계가 끝날 때마다 "직접 하려면 이렇게 쳐 보세요" 프롬프트를 알려 줍니다.
- 사장님이 말하지 않은 사실(경력·수상·가격·주소 등)은 지어내지 않습니다.
- 모든 홍보물에 "처음으로" 버튼이 있어 모음 페이지로 쉽게 돌아갑니다.

## 설치

Claude Code에서:

```
/plugin marketplace add hyunkwang1052/openlab
/plugin install marketing-kit@openlab
```

## 사용

```
우리 가게 홍보물 만들어줘
```

단계별로도 쓸 수 있어요.

- `내 가게 인터뷰해줘` → 1단계만
- `이 사이트 보고 내 브랜드 디자인 만들어줘` → 2단계만
- `내 브랜드로 카드뉴스 만들어줘` → 만들어 둔 브랜드 스킬로 새 홍보물
- `지금 만든 브랜드 키트를 Vercel로 올려 줘` → 4단계

작업 파일은 현재 프로젝트의 `_workspace/marketing-kit/<가게-슬러그>/` 에 쌓입니다.

## 구성

```
skills/
  marketing-kit/        오케스트레이터 (+ references/output-specs.md, references/shells/*.html 홍보물 셸)
  marketing-interview/  1단계 인터뷰
  marketing-sheet/      2단계 디자인 시트 → 브랜드 스킬 패키징
agents/
  marketing-interviewer.md
  marketing-sheet-maker.md   (2단계 빌드 서브에이전트)
  marketing-kit-builder.md   (3단계 홍보물 4종 서브에이전트)
```

## 필요한 것 (4단계 올리기를 쓸 때만)

- **Node.js** + **Vercel CLI** (`npm i -g vercel`) 와 Vercel 무료 계정. 로그인은 사장님이 직접 합니다.
- 카톡 미리보기 그림(`og.png`)은 Chrome 또는 Edge 헤드리스로 만듭니다. 둘 다 없으면 그림 없이 진행합니다.

## 선택 플러그인

- 한국어 문장 다듬기에 `humanize-korean` 플러그인이 있으면 함께 씁니다. 없어도 동작합니다.
